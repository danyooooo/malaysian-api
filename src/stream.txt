# RadioMY stream API endpoint reference
# Updated: 2026-10-25 (Asia/Kuala_Lumpur)
# Source: src/router.js and its handlers in the RadioMY-cf-v2 project.
# Routes below are relative to the base URL above unless marked root-only.
# The same routes support no prefix or a custom prefix before
# a recognized route target. Provider aliases are specific to each section.
# Methods shown are the intended client methods; most GET routes do not
# enforce methods. OPTIONS on any path returns 204 with CORS headers.
# This is a source inventory; upstream playback availability can vary.

  Response: 204; CORS preflight (handled before maintenance and routing).

      An explicit provider in the route overrides the query parameter.
    channel: <canonical provider:slug, slug, alias, upstream ID, name, or channel number>
    slug: <channel selector> (alias; used if channel is absent)
    stbNumber: <channel selector> (alias; used if channel and slug are absent)
    date: <YYYY-MM-DD or YYYYMMDD> (default: Malaysia today)
    dateStart: <date> (alias; used if date is absent)
    day: <date> (alias; used if date and dateStart are absent)

    category: <string>
    refresh: [true, false] (default: false)
  Response: {ok, provider, date, timezone, mode, totalChannels, channels[]}.
    No channel: summary mode. Selected channel: one channel with schedule[].
    channel/slug/stbNumber and date/dateStart/day use the precedence above.
    Unknown or ambiguous channel selectors are rejected; no substring guessing.
    Without provider, a recognized channel can infer the provider; date-only
    requests default to Unifi. No provider, channel, or date returns 400.
    Syok podcasts are separate and are not an EPG provider.

# Exceptions and selector precedence are described at the relevant endpoint.
